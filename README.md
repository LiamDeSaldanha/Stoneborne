# 🎮 Stoneborne

A game developed during a 3-week game jam hosted by the Sozo Labs. This project was my first end-to-end experience with Unity and involved learning, designing, developing, publishing, and presenting a complete game.

## 📅 Duration
**3 Weeks** | Hosted by: Sozo Labs

## 🧠 What I Did

- Completed Unity's **"Create with Code"** and **"Essential Pathway"** courses to build a solid foundation in C# and Unity engine workflows.
- Created a **Game Design Document (GDD)** to outline the game’s core mechanics, scope, visual style, and user experience goals.
- Implemented the game using **Unity**, with weekly iterations based on feedback from mentors.
- Published the final game on **[Itch.io](https://desaldanha.itch.io/stoneborne)**.
- Prepared and delivered a presentation showcasing the development process and answered technical/creative questions from the Sozo team.

## 🛠️ Tech Stack

- **Engine:** Unity
- **Language:** C#
- **Platform:** WebGL / Windows 
- **Tools:** Git , Itch.io, Unity Learn
